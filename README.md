# Expedition Oz

Website for Expedition Oz — luxury sailing charters through the Ningaloo, Western Australia.

**Stack:** Astro 6 · Sanity v3 · GSAP · Tailwind v4 · Netlify

See `CLAUDE.md` for the full project reference: design tokens, phase status, component conventions, and architectural decisions.

## Dev commands

```bash
npm install       # Install dependencies
npm run dev       # Dev server at http://localhost:4321
npm run build     # Build static site to dist/
npm run preview   # Preview built site
```
